# אתגר המפות הישראלי 2026

אתר סטטי בעברית לאתגר המפות הישראלי של נובמבר 2026, המתוחזק על ידי [האגודה הישראלית לכרטוגרפיה](https://www.isrcartogis.org/). האתר נפרד מטופס ההגשה ומאחסון המפות.

אפשר להצטרף גם ל[קבוצת הוואטסאפ של האתגר](https://chat.whatsapp.com/Cux5kvuhouNCTsopKeig8c).

## פיתוח מקומי

אפשר לפתוח את `index.html` בדפדפן או להפעיל שרת סטטי מקומי מתוך התיקייה `site`.

## פרסום

האתר מיועד ל־GitHub Pages, בפרסום מתיקיית השורש של ענף `main`. אין לשמור כאן סודות, קובצי הגשה פרטיים, קובצי מקור של Apps Script או מזהי גישה.

## מקורות תוכן

רשימת הנושאים מבוססת על [אתגר 2026 הרשמי](https://30daymapchallenge.com/2026/). האתר הישראלי הוא גלריה קהילתית מקומית ואינו האתר הרשמי של האתגר העולמי.

דף הבית מציג קרוסלה של תמונות מפות שפורסמו בגלריה, עם קישור לעמוד העצמאי של כל מפה; ההחלפה האוטומטית נעצרת בהעדפת תנועה מופחתת, במעבר עכבר או במיקוד מקלדת, ונפסקת להמשך הביקור לאחר מעבר ידני למפה קודמת או הבאה. הקרוסלה, הדפים היומיים, הגלריה ועמוד המפה העצמאי טוענים את ההגשות המאושרות מתוך `data/gallery.json`. הדפים היומיים ועמוד המפה מציגים גם מפות אינטראקטיביות וכוללים פתיחה בחלון חדש ובמסך מלא. לכל פריט גלריה יש כתובת ייחודית ב־`map.html?id=<public-id>`; המזהה הוא מזהה גלריה אקראי, לא מזהה Drive.
